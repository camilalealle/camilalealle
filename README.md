## Featured Projects

### 🛒 [RappiPlus | E-commerce Business Analytics](https://github.com/camilalealle/rappiplus-business-analysis)

**Python · SQL · Power BI · Statistical Analysis**

End-to-end analysis of e-commerce performance, covering profitability, customer behavior, conversion funnels, cohort retention, and A/B testing.

**Key findings:**
- Identified a product with an estimated **−8.63% gross margin**.
- Found opportunities to investigate checkout friction and customer retention.
- Evaluated a checkout A/B test with no statistically significant improvement (**p = 0.4161**).

**Business value:** Translated financial, behavioral, and experimental data into recommendations for profitability and customer experience.

[View Project](https://github.com/camilalealle/rappiplus-business-analysis)

---

### 📈 [MercadoLibre | Conversion Funnel & Cohort Retention](https://github.com/camilalealle/mercadolibre-funnel-retention-analysis)

**SQL (SQLite) · Python · Pandas · Matplotlib · HTML**

Analysis of user behavior across the purchase journey and post-registration activity, using an educational MercadoLibre-themed dataset.

**Key findings:**
- Identified an **87.69% drop-off** between product selection and adding to cart in the strict chronological funnel.
- Found that daily user activity declined from **97.88% at D0 to 51.35% at D1**.
- Analyzed retention across monthly cohorts, countries, and devices.

**Business value:** Identified opportunities to investigate conversion friction and improve early user engagement.

[View Project](https://github.com/camilalealle/mercadolibre-funnel-retention-analysis) · [Live Dashboard](https://camilalealle.github.io/mercadolibre-funnel-retention-analysis/dashboard/mercadolibre_dashboard_ejecutivo.html)
